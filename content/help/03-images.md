## Image ke usool

| Cheez | Usool |
|---|---|
| **Shape** | Landscape 4:3. Behtareen size **1448 x 1086** (kam az kam 1200 x 900) |
| **Format** | **WebP** sab se behtar, JPG bhi theek. PNG sirf logo ke liye |
| **File size** | **1 MB se kam** (300-500 KB behtareen) |
| **Naam** | chhote English huroof aur dash: `mailer-box-kraft-front.webp`. Space ya Urdu nahi |
| **Logo** | Kone mein Printy Packaging logo |
| **Doosre brand** | Kisi aur company ka naam ya logo wali image **na lagayein** |

**Free tools:**
- Size aur WebP ke liye: **squoosh.app** (browser mein chalta hai, free). Image daalein, "WebP" chunein, width 1448 karein, phir download.
- Logo lagane ke liye: **Canva** ya **Photopea** (free, Photoshop jaisa).

## Product ki images badalna

1. Admin mein **Product Images**, phir **Product galleries** kholein.
2. Product dhoondhein, jaise "Bakery Boxes", aur us par click karein.
3. **Images** mein:
   - **Nayi image:** "Add images" dabayein, image upload karein, description aur short title likhein.
   - **Image badalni ho:** us image par click karein, phir "Choose different image".
   - **Tarteeb badalni ho:** image ko upar-neeche ghasitein. **Sab se upar wali image main image aur product card banti hai.**
   - **Hatana ho:** image ke saath "x" dabayein.
4. Zyada se zyada **12 images**. Kam az kam 1 lazmi hai.
5. **Product slug** wala khana **na badlein**.
6. **Publish** dabayein.

## Blog ki cover image

Blog kholein, **Cover image** mein nayi image lagayein aur description likhein, phir Publish.

## Uploaded images kahan jati hain?

Admin se upload hui images `public/images/uploads/` folder mein jati hain. Purani images `public/images/products/...` mein hain. Dono theek kaam karti hain.

## Masla: image nazar nahi aa rahi

- 2-3 minute intezar karein, phir **Ctrl + F5** dabayein.
- File ka naam check karein: space ya ajeeb nishaan to nahi?
- File 5 MB se bari ho to chhoti karein (squoosh.app) aur dobara lagayein.
- Phir bhi na chale to **Troubleshooting** guide dekhein.
