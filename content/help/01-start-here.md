## Ye admin panel kya hai?

Ye aap ki website ka "control room" hai: **printypackaging.com/admin**

Yahan se aap bina code ke ye sab kar sakte hain:

| Hissa | Kya karta hai |
|---|---|
| **Blogs** | Naya blog likhna, purana edit karna, hide ya delete karna |
| **Product Images** | Har product ki gallery ki images badalna, tarteeb badalna |
| **Business Info & Social** | MOQ, production time, phone, reviews, sales team, social links |
| **Backlinks Tracker** | Backlinks ka record (sirf aap ke liye, website par nahi dikhta) |
| **Help & Guides** | Yehi guides. Aap apni guide bhi add kar sakte hain |

## Kaam kaise hota hai (seedha sa)

1. printypackaging.com/admin kholein aur **Login with GitHub** dabayein.
2. Jo badalna hai wo kholein aur tabdeeli karein.
3. Upar **Publish** dabayein, phir **Publish now**.
4. **2-3 minute** baad tabdeeli website par live ho jati hai (Vercel khud update karta hai).

## Zaroori baatein

- Har Publish GitHub mein ek "commit" (mehfooz version) banata hai. Ghalti ho jaye to purana version wapas aa sakta hai. Dekhein: **Troubleshooting** guide.
- Ek waqt mein ek hi shakhs edit kare, warna ek ki tabdeeli doosre par chadh sakti hai.
- Publish ke baad website par purana dikhe to **Ctrl + F5** dabayein.
- Koi cheez samajh na aaye to pehle yahan ki guides dekhein, phir **Get help from any AI** guide.
