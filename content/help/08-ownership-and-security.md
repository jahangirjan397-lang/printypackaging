Aap ki website 5 cheezon par khari hai. **Har ek aap ke apne naam aur apni email par honi chahiye.** Jis ke paas ye 5 hain, website usi ki hai.

| # | Cheez | Kahan | Owner kaun hona chahiye |
|---|---|---|---|
| 1 | **Domain** (printypackaging.com) | Hostinger | **Aap** |
| 2 | **Code** | GitHub (jahangirjan397-lang/printypackaging) | **Aap** |
| 3 | **Hosting** | Vercel | **Aap** |
| 4 | **Business email** | Hostinger Mail | **Aap** |
| 5 | **Leads Sheet, Search Console, Analytics** | Google account | **Aap** |

## Aaj hi karein (sirf ek dafa)

1. **2-step verification** har account par on karein: Hostinger, GitHub, Vercel, Google/Gmail. Isse password chori ho bhi jaye to koi login nahi kar sakta.
2. **Backup codes** (2-step ke saath milte hain) print karke ghar mein mehfooz rakhein. Phone gum ho jaye to yehi kaam aayenge.
3. **Password manager** use karein (Bitwarden free hai). Har account ka alag aur mazboot password.
4. Hostinger mein domain par **auto-renew** on karein aur card update rakhein. Domain expire ho jaye to koi aur khareed sakta hai.
5. Recovery email aur phone number apne hi rakhein, kisi developer ke nahi.

## Developer ya freelancer ko kaam dena (mehfooz tareeqa)

**Kabhi na dein:** apna password, 2-step codes, ya account ka "owner" rutba.

**Dein to sirf ye:**
- **GitHub**: repo, phir **Settings, phir Collaborators, phir Add people**. Developer ka apna GitHub account. Kaam ke baad **Remove** kar dein.
- **Vercel** (sirf zaroorat ho to): Team, phir Members, phir Invite. Kaam ke baad hata dein.
- **Hostinger**: aam taur par zaroorat nahi. Ho to "Account access / sharing" se sirf zaroori hissa.
- **Google Sheet**: sirf "Editor" share, aur baad mein hata dein.

**Kaam shuru karne se pehle likh kar tay karein:** kya banana hai, kab tak, kitne paise, aur ye jumla: *"All code and content created for printypackaging.com belongs to the owner."*

## Access wapas lena (jab bhi chahein, bina puche)

| Jagah | Kaise |
|---|---|
| GitHub | Repo, phir Settings, phir Collaborators, aur naam ke saath **Remove** |
| Vercel | Team, phir Members, aur naam ke saath **Remove** |
| Google Sheet | Share, aur naam ke saath **Remove access** |
| Admin panel | Admin GitHub se chalta hai. GitHub se hata diya to admin bhi band |
| Shak ho | Us account ka password badlein aur "sign out of all devices" karein |

## Backup (mahine mein ek dafa, 2 minute)

1. github.com par repo kholein, phir hara **Code** button, phir **Download ZIP**.
2. ZIP ko Google Drive aur ek USB mein rakhein.
3. Google Sheet: **File, phir Download, phir Excel**.

Is ZIP mein poori website hai: code, blogs, images aur settings. Kuch bhi ho jaye, koi bhi developer isse website dobara khari kar sakta hai.

## Agar koi dhamki de ya access na chhore

1. Ghabrayein nahi. Upar ki table se **access foran hata dein**.
2. Us ne jin accounts ka password dekha ho, un sab ke **password badlein**.
3. Khatre ki baat ho to screenshots rakhein. GitHub, Vercel aur Hostinger ke **support** ko likhein ke aap asal owner hain. Wo ownership saabit hone par madad karte hain.
4. Mahine wala backup ZIP aap ke paas ho to website kisi bhi haal mein wapas aa sakti hai.
